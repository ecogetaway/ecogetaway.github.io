The missing infrastructure around open-source contribution.

Code review has linters, CI, and named owners. Localization, accessibility work, and AI-assisted contribution often do not.

I study that asymmetry in public repositories, then publish the smallest artifact the evidence supports: a linter, a review rubric, a template, or a draft schema.

Four lines of inquiry, one method

Each begins with primary-source evidence and ends with a public artifact small enough for a real project to test.

Tool on PyPILocalization

Localization & language inclusion

Most open source ships English-first. The bottleneck on Indic locales is rarely translation quality — it is review and operations. This work follows how under-served locales get reviewed upstream, and what maintainers need when they cannot read every language they ship.

Output: i18n-security-lint, a CI linter for four defect classes in translated strings: bidi overrides, XSS fragments, format-string drift, interpolation breakage. Plus field reports and contribution evidence.

Active researchAccessibility

Accessibility contribution review

We scored seven real accessibility PRs against a 12-point rubric. None reached the mature band, and the most heavily reviewed one tied for the lowest score. Reusable ACCESSIBILITY.md, issue, and PR templates make the next fix reviewable by a non-expert.

Tool on PyPIDocumentation

Machine-operable documentation

readme-ci finds the code examples in Markdown docs and runs them in a locked-down sandbox, so “our examples still work” becomes a CI check instead of a hope. First tool of Machine-Operable Open Source (opens in a new tab), a program on repositories that machines, not only people, now read.

The research method is deliberately narrow

Evidence before visibility, and a public artifact only when the evidence justifies one.

  1. ObserveStudy real projects and primary sources.
  2. NameDefine the recurring infrastructure gap precisely.
  3. TestScore or catalogue what communities already invented.
  4. ShipPublish a small reference artifact.
  5. Invite critiqueKeep the evidence and decisions public.
